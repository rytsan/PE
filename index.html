Formulário de Engenharia (Resumo dos 9 Módulos)
Módulo 1: Probabilidade Fundamental
  • $P(A \cup B) = P(A) + P(B) - P(A \cap B)$
  • $P(A|B) = \frac{P(A \cap B)}{P(B)}$
  • Independência: $P(A \cap B) = P(A) \cdot P(B)$
  • Probabilidade Total: $P(B) = \sum P(A_i) P(B|A_i)$
  • Bayes: $P(A_j|B) = \frac{P(A_j) P(B|A_j)}{\sum P(A_i) P(B|A_i)}$
  • Sistemas em série: $R_s = \prod R_i$
  • Sistemas em paralelo: $R_p = 1 - \prod (1 - R_i)$
Módulo 2: Variáveis Aleatórias Discretas
  • $\sum p(x) = 1, \quad p(x) \ge 0$
  • $F(x) = P(X \le x) = \sum_{t \le x} p(t)$
  • $E[X] = \mu = \sum x p(x)$
  • $Var(X) = \sigma^2 = E[X^2] - (E[X])^2$
  • $E[aX + b] = a E[X] + b$
  • $Var(aX + b) = a^2 Var(X)$
  • $\sigma = \sqrt{Var(X)}$
Módulo 3: Modelos Discretos
  • Uniforme: $P(X=x) = \frac{1}{k}$, $E[X] = \frac{a+b}{2}$
  • Binomial: $P(X=k) = \binom{n}{k} p^k (1-p)^{n-k}$
  • $E[X]_{Bin} = np, \quad Var(X)_{Bin} = np(1-p)$
  • Poisson: $P(X=k) = \frac{e^{-\lambda} \lambda^k}{k!}$
  • $E[X]_{Poi} = \lambda, \quad Var(X)_{Poi} = \lambda$
  • Aproximação: $\lambda = np$ ($n \ge 20, p \le 0.05$)
Módulo 4: Variáveis Aleatórias Contínuas
  • $\int_{-\infty}^{+\infty} f(x) dx = 1, \quad f(x) \ge 0$
  • $P(a \le X \le b) = \int_a^b f(x) dx$
  • $F(x) = \int_{-\infty}^x f(t) dt \implies f(x) = F'(x)$
  • $E[X] = \int x f(x) dx$
  • $E[X^2] = \int x^2 f(x) dx$
  • $Var(X) = E[X^2] - (E[X])^2$
  • Mediana: $F(m) = 0.50$
Módulo 5: Modelos Contínuos
  • Uniforme: $f(x) = \frac{1}{b-a}$, $Var(X) = \frac{(b-a)^2}{12}$
  • Normal: $Z = \frac{X - \mu}{\sigma} \sim N(0, 1)$
  • Simetria: $\Phi(-z) = 1 - \Phi(z)$
  • Exponencial: $f(x) = \lambda e^{-\lambda x}$, $F(x) = 1 - e^{-\lambda x}$
  • $E[X]_{Exp} = \frac{1}{\lambda} = \text{MTTF}$, $Var(X) = \frac{1}{\lambda^2}$
  • Confiabilidade: $R(t) = e^{-\lambda t}$
Módulo 6: Estatística Descritiva
  • Média: $\bar{x} = \frac{1}{n} \sum x_i$
  • Variância: $s^2 = \frac{1}{n-1} \sum (x_i - \bar{x})^2$
  • Desvio padrão: $s = \sqrt{s^2}$
  • Coef. Variação: $CV = \frac{s}{\bar{x}} \times 100\%$
  • $IQR = Q_3 - Q_1$
  • Limites Boxplot: $[Q_1 - 1.5 IQR; \; Q_3 + 1.5 IQR]$
Módulo 7: Estimação e TCL
  • TCL ($n \ge 30$): $\bar{X} \sim N(\mu, \sigma^2/n)$
  • Erro Padrão: $SE = \frac{\sigma}{\sqrt{n}}$
  • IC ($\sigma$ conhec.): $\bar{x} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}$
  • IC ($\sigma$ desconh.): $\bar{x} \pm t_{\alpha/2, n-1} \frac{s}{\sqrt{n}}$
  • Tamanho amostral: $n = \left( \frac{z_{\alpha/2} \sigma}{E} \right)^2$
  • IC Proporção: $\hat{p} \pm z_{\alpha/2} \sqrt{\frac{\hat{p}(1-\hat{p})}{n}}$
Módulo 8: Testes de Hipótese
  • Estatística $Z$: $z_{\text{calc}} = \frac{\bar{x} - \mu_0}{\sigma / \sqrt{n}}$
  • Estatística $t$: $t_{\text{calc}} = \frac{\bar{x} - \mu_0}{s / \sqrt{n}}$
  • Regra: Se $p\text{-valor} \le \alpha \implies$ Rejeita $H_0$
  • Erro I: Rejeitar $H_0$ verdadeira ($\alpha$)
  • Erro II: Não rejeitar $H_0$ falsa ($\beta$)
  • Poder do teste: $1 - \beta$
  • Qui-Quadrado: $\chi^2_{\text{calc}} = \sum \frac{(O_i - E_i)^2}{E_i}$ ($gl = k-1-m$)
Módulo 9: Controle Estatístico (CEP)
  • Limites $3\sigma$: $LC = \mu, \; LSC = \mu + 3\sigma, \; LIC = \mu - 3\sigma$
  • Gráfico $\bar{X}$: $LSC = \bar{\bar{X}} + A_2 \bar{R}, \; LIC = \bar{\bar{X}} - A_2 \bar{R}$
  • Gráfico $R$: $LSC = D_4 \bar{R}, \; LIC = D_3 \bar{R}$
  • Gráfico $p$: $\bar{p} \pm 3\sqrt{\frac{\bar{p}(1-\bar{p})}{n}}$
  • Capacidade: $C_p = \frac{LSE - LIE}{6\sigma}$
  • Capacidade real: $C_{pk} = \min\left(\frac{LSE-\mu}{3\sigma}, \frac{\mu-LIE}{3\sigma}\right)$
